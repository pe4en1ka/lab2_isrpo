# Общее описание решения

Проект предоставляет простые функции для геометрических вычислений. Его можно использовать из интерактивного интерпретатора Python или импортировать в другую программу. Отдельного интерфейса командной строки нет: запуск файлов напрямую не выводит результаты, поскольку файлы содержат только функции.

## Устройство проекта

Он состоит из трёх независимых модулей:

1. `circle.py` вычисляет площадь круга и длину окружности с использованием константы `math.pi`.
2. `rectangle.py` вычисляет площадь и периметр прямоугольника.
3. `triangle.py` вычисляет площадь по основанию и высоте, периметр по трём сторонам и проверяет равенство сторон.

Функции принимают аргументы, возвращают результат и сами ничего не печатают. Для вывода используйте `print`. Они не читают файлы, не запрашивают ввод и не сохраняют данные.

## Формулы

| Фигура | Площадь | Периметр |
| --- | --- | --- |
| Круг радиуса `r` | `π * r²` | `2 * π * r` |
| Прямоугольник со сторонами `a`, `b` | `a * b` | `2 * (a + b)` |
| Треугольник с основанием `a` и высотой `h`; сторонами `a`, `b`, `c` | `a * h / 2` | `a + b + c` |

Длины заданы в условных единицах, периметр получается в них же, а площадь — в квадратных условных единицах.

## Ограничения

- Предполагается использование чисел `int` или `float`.
- Проверок типов, положительности размеров и неравенства треугольника нет.
- Нулевые и отрицательные значения могут дать численный результат, не имеющий смысла для обычной геометрической фигуры.
- Проверка равенства сторон использует точное сравнение `==`, без допуска для погрешности вычислений с `float`.
- Имена функций в разных модулях совпадают; обращение через имя модуля, например `circle.area(3)`, позволяет явно указать фигуру.
