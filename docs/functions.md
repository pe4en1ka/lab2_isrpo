# Справочник функций

Ниже описаны все семь функций проекта. Примеры запускаются из корня репозитория в Python 3. Типы результатов указаны для аргументов `int` и `float`.

## Модуль circle

### circle.area(r)

Вычисляет площадь круга по формуле `π * r ** 2`.

- **Параметр:** `r` — радиус круга.
- **Результат:** площадь, число `float`.

```python
import circle

print(round(circle.area(3), 2))  # 28.27
```

### circle.perimetr(r)

Вычисляет длину окружности по формуле `2 * π * r`.

- **Параметр:** `r` — радиус круга.
- **Результат:** длина окружности, число `float`.

```python
import circle

print(round(circle.perimetr(3), 2))  # 18.85
```

## Модуль rectangle

### rectangle.area(a, b)

Вычисляет площадь прямоугольника по формуле `a * b`.

- **Параметры:** `a`, `b` — длины двух смежных сторон.
- **Результат:** площадь; `int`, если оба аргумента целые, иначе `float`.

```python
import rectangle

print(rectangle.area(3, 4))  # 12
```

### rectangle.perimetr(a, b)

Вычисляет периметр прямоугольника по формуле `2 * (a + b)`.

- **Параметры:** `a`, `b` — длины двух смежных сторон.
- **Результат:** периметр; `int`, если оба аргумента целые, иначе `float`.

```python
import rectangle

print(rectangle.perimetr(3, 4))  # 14
```

## Модуль triangle

### triangle.area(a, h)

Вычисляет площадь треугольника по формуле `a * h / 2`.

- **Параметр `a`:** длина основания.
- **Параметр `h`:** высота, проведённая к этому основанию.
- **Результат:** площадь, число `float`, в том числе при целых аргументах.

```python
import triangle

print(triangle.area(6, 4))  # 12.0
```

### triangle.perimetr(a, b, c)

Вычисляет периметр треугольника как сумму `a + b + c`.

- **Параметры:** `a`, `b`, `c` — длины трёх сторон.
- **Результат:** периметр; `int`, если все аргументы целые, иначе `float`.

```python
import triangle

print(triangle.perimetr(3, 4, 5))  # 12
```

Функция не проверяет, существует ли треугольник с указанными сторонами.

### triangle.SideEqualityCheck(a, b, c)

Проверяет равенство трёх значений выражением `a == b == c`.

- **Параметры:** `a`, `b`, `c` — длины трёх сторон.
- **Результат:** `bool`: `True`, если все три значения равны, иначе `False`.

```python
import triangle

print(triangle.SideEqualityCheck(5, 5, 5))  # True
print(triangle.SideEqualityCheck(3, 4, 5))  # False
print(triangle.SideEqualityCheck(5, 5, 3))  # False
```

> Равенство значений само по себе не подтверждает корректность треугольника: например, для `(0, 0, 0)` функция тоже вернёт `True`. Сравнение дробных чисел выполняется без допуска.
