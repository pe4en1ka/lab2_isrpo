# Геометрические вычисления

Набор функций на Python для вычисления площади и периметра круга, прямоугольника и треугольника. Для треугольника также доступна проверка равенства трёх сторон.

## Требования

Нужен **Python 3**. Дополнительные библиотеки устанавливать не требуется: используется только стандартный модуль `math`.

## Быстрый старт

Откройте терминал в корне проекта и запустите интерпретатор:

```bash
python3
```

Выполните пример:

```python
import circle
import rectangle
import triangle

print(round(circle.area(3), 2))  # 28.27
print(rectangle.perimetr(3, 4))  # 14
print(triangle.area(6, 4))  # 12.0
print(triangle.SideEqualityCheck(5, 5, 5))  # True
```
